# منشور پروژه ریاضی‌یار پایه اول — نسخه Android Native V2 (`docs/PROJECT_CHARTER.md`)

## ۱. هدف محصول
تبدیل MVP محدود نسخه ۱.۰.۳ (صرفاً ۲ درس شمارش در Flutter) به یک محصول جامع، پایدار، کودک‌محور و ۱۰۰٪ آفلاین **Android Native (Kotlin + Jetpack Compose)** که تمام ۸ فصل و ۳۹ درس کتاب ریاضی پایه اول ابتدایی را با ۶ ابزار دست‌ورزی تعاملی، موتور یادگیری تطبیقی مبتنی بر الگوریتم استاندارد SuperMemo SM-2، مسیر جبرانی هوشمند و داشبورد تحلیلی والدین پوشش دهد.

## ۲. اصول غیرقابل مذاکره
1. **حداقل‌گرایی داده و امنیت کودک:** صفر مجوز سیستمی، صفر دسترسی شبکه در اپ، صفر تبلیغات یا ردیاب، غیرفعال بودن کامل Android Backup (`allowBackup="false"`).
2. **صداقت مهندسی و عدم Hardcode:** هیچ امتیاز، ستاره، گزینه سؤال یا تکمیل درسی به‌صورت ساختگی یا ثابت تولید نمی‌شود.
3. **حفظ کامل میراث پروژه:** تاریخچه Git و سورس کامل نسخه Flutter v1.0.3 در `legacy/flutter-v1.0.3/` و تگ `archive/flutter-v1.0.3` حفظ شده است.
