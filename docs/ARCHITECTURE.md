# معماری و ساختار پروژه — ریاضی‌یار (MVP)

نسخه سند: ۱.۰.۰ | تاریخ: ۲۰۲۶-۱۰-۱۷ | وضعیت: منطبق با کد واقعی (کامیت `06cb56d`)

## ۱) نمای کلی

اپلیکیشن Flutter برای اندروید، فارسی و RTL، کاملاً آفلاین. معماری لایه‌ای ساده بدون
فریم‌ورک state-management خارجی (فقط `ChangeNotifier` و تزریق وابستگی دستی) تا
سطح پیچیدگی MVP پایین بماند.

```
┌─────────────────────────────────────────────┐
│  UI (lib/ui) — ۸ صفحه + ویجت‌های مشترک       │  فارسی، RTL، دکمه‌های بزرگ
├─────────────────────────────────────────────┤
│  Session Engine (core/engine)               │  LessonSession (ماشین حالت خالص)
│  Evaluator — ارزیابی، تسلط، امتیاز           │  مستقل از UI و تست‌پذیر
├─────────────────────────────────────────────┤
│  Content (core/content)                     │  JSON نسخه‌دار + اعتبارسنج
├─────────────────────────────────────────────┤
│  Services                                   │
│   • GuideEngine (محلی قاعده‌محور)            │  + HttpAiGuideClient (اختیاری)
│   • TtsService / SttService (قرارداد مستقل) │  پیاده‌سازی واقعی + Stub
│   • SyncContract (فقط قرارداد — Noop)       │  صادقانه: پیاده‌سازی نشده
├─────────────────────────────────────────────┤
│  Storage (core/storage) — sqflite/SQLite    │  attempts, progress, settings, sync_queue
├─────────────────────────────────────────────┤
│  Models (core/models) — کلاس‌های داده خالص  │  Lesson, Activity, Question, …
└─────────────────────────────────────────────┘
```

## ۳) تصمیم‌های کلیدی معماری (با دلیل)

1. **امتیاز = نخستین تلاشِ درستِ هر پرسش.** تلاش‌های اصلاحی برای تمرین‌اند و
   امتیاز را بالا نمی‌برند تا تصویر واقعی یادگیری حفظ شود. همه تلاش‌ها در
   `attempts` ثبت و در گزارش والدین نمایش داده می‌شود. (تست: `lesson_session_test`)
2. **محتوا از کد جدا.** افزودن درس = افزودن یک فایل JSON + یک خط در فهرست
   (`LessonContentLoader.bundledLessonAssets`)؛ موتور تغییر نمی‌کند.
3. **راهنمای محلی قاعده‌محور به‌عنوان پیش‌فرض.** هیچ ادعای «AI» بدون سرویس واقعی.
   راهنمای آنلاین فقط با پیکربندی سرور واسط فعال می‌شود؛ خروجی ساختاریافته
   (`{"message","action"}`، حداکثر ۳۰۰ نویسه) و در خطا fallback به محلی.
4. **هیچ کلید API در کد/APK نیست.** آدرس سرور راهنما فقط از
   `--dart-define=RIAZIYAR_GUIDE_ENDPOINT=...` تزریق می‌شود؛ پیش‌فرض = غیرفعال.
5. **همگام‌سازی فقط قرارداد.** `NoopSyncService` چیزی ارسال نمی‌کند و صریحاً
   «تکمیل‌نشده» است؛ جدول `sync_queue` برای آینده محفوظ است.
6. **گرافیک اشیا برداری با CustomPainter** — هیچ فایل تصویری ساختگی یا منبع
   دارای حق نشر استفاده نشده است.
7. **معیار تسلط قابل پیکربندی** (`masteryThreshold` در تنظیمات، پیش‌فرض ۰.۷۵،
   حداقل ۲ تلاش) — «شاخص رفتاری ساده»، نه ادعای روان‌سنجی.
8. **path_provider_android به 2.2.23 پین شد** (dependency_overrides): نسخه 2.3.x
   پیاده‌سازی JNI/C++ دارد که NDK کامل می‌خواهد؛ 2.2.x جاوایی و پایدار است.
9. **AGP 8.13** (به‌جای 9.1): با Gradle 9.3.1 سازگار است و زنجیره ساخت سبک‌تری
   در محیط‌های محدود دارد. `ndkVersion` صریحاً به نسخه نصب‌شده (28.2) پین شده است.

## ۴) جریان‌های اصلی

- **شروع**: اسپلش → خانه کودک (سلام + دکمه بزرگ «ادامه یادگیری» + فهرست درس‌ها).
- **جلسه درس**: معرفی درس → صفحه فعالیت (شمارش/تطبیق) → بازخورد فوری دیالوگی →
  تکرار پرسش تا ۳ تلاش → نتیجه (ستاره + پیام تشویقی) → تکرار یا خانه.
- **والدین**: گیت محافظتی (جمع دو رقمی) → داشبورد (فقط داده واقعی) + سوییچ‌ها.
- **آزمون پایان واحد**: `kind: "quiz"`؛ امتیاز آن از نخستین تلاش هر پرسش در
  پایگاه داده محاسبه می‌شود (`quizFirstTryScore`).
