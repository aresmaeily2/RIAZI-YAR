## ۱) خلاصه محصول

«ریاضی‌یار» یک اپلیکیشن اندروید فارسی/RTL آفلاین برای کودکان ۶-۷ ساله است که
واحد «شمارش اشیا» ریاضی پایه اول را با دو نوع فعالیت تعاملی (شمارش و انتخاب
عدد، تطبیق عدد با دسته‌ها)، بازخورد فوری محترمانه، راهنمای گام‌به‌گام بدون لو
دادن پاسخ، آزمون کوتاه پایان واحد و داشبورد والدین ارائه می‌کند. همه داده‌ها
محلی است، پشتیبان‌گیری غیرفعال است و میکروفون در این نسخه در دسترس نیست.

## ۳) موارد ناقص یا غیرفعال (صداقت کامل)

| مورد | وضعیت دقیق |
|---|---|
| اجرای روی دستگاه/شبیه‌ساز | **NOT RUN** (محیط فاقد دستگاه) |
| کیفیت صوت (TTS) روی دستگاه | پیاده‌سازی واقعی؛ **NOT RUN** |
| ورودی گفتار (STT) | **غیرفعال امن** — چرایی و چک‌لیست: `AI_STT_TTS.md` §۲ |
| همگام‌سازی ابری | فقط قرارداد (`NoopSyncService`) — چیزی ارسال نمی‌کند |
| راهنمای آنلاین | کلاینت سخت‌سازی‌شده؛ سرور واسط وجود ندارد ⇒ پیش‌فرض غیرفعال؛ چرخه HTTPS کامل: **NOT RUN** |
| محتوای درس‌ها | نمونه و **نیازمند بازبینی معلم** (برچسب در UI) |
| امضای انتشار | **BLOCKED** — keystore ندارد؛ کلید debug فقط برای «تست داخلی» برچسب‌دار |
| x86_64 در APK | ساخته نشده (محدودیت دیسک محیط)؛ arm+arm64 ساخته شد |

## ۴) انتخاب‌های فنی و دلیل

- **Flutter/Dart**: یک کدبیس بومی اندروید، UI کودک‌پسند پایدار، ابزار تست کامل.
- **sqflite/SQLite**: ذخیره‌سازی محلی استاندارد، تراکنش، بدون سرور.
- **بدون پکیج state-management**: کاهش وابستگی؛ ChangeNotifier کافی.
- **CustomPainter**: اشیا برداری بدون فایل تصویری/حق نشر.
- **flutter_tts**: موتور دستگاه، بدون کلید؛ حذف `speech_to_text` در ۱.۰.۱.
- **AGP 8.13 + Gradle 9.3.1 + NDK 28.2 پین‌شده**: زنجیره واقعاً بیلد‌شده.
