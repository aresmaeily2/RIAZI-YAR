# PROJECT CHARTER — ریاضی‌یار

نسخه سند: ۱.۰ | تاریخ: ۲۰۲۶-۱۰-۱۸ | وضعیت: فعال (MVP)

## هدف
اپلیکیشن آموزش ریاضی فارسی/RTL برای کودک ۶–۷ ساله ایرانی، واحد «شمارش
اشیا» کتاب اول ابتدایی، آفلاین‌اول، با امنیت و حریم خصوصی کودک به‌عنوان
قید سخت.

## قواعد ثابت (غیرقابل نقض)
1. **آفلاین‌اول**: درس، تمرین، ذخیره پیشرفت و راهنمای محلی بدون اینترنت
   کامل کار می‌کنند؛ هر سرویس آنلاین «اختیاری، پیش‌فرض خاموش، با رضایت
   آگاهانه والد» است.
2. **ایمنی کودک**: بدون جمع‌آوری داده شخصی، بدون تبلیغ، بدون مجوز
   غیرضروری (RECORD_AUDIO حذف شده)، allowBackup=false، بدون کلید/راز در
   سورس.
3. **صمیمیت با حقیقت**: هیچ تست اجرا‌نشده PASS اعلام نمی‌شود؛ هر ادعا
   شاهد قابل بازبینی دارد؛ وضعیت‌های مجاز: PASS / FAIL / NOT RUN / BLOCKED.
4. **دامنه MVP**: گسترش دامنه فقط با تصمیم ثبت‌شده در DECISION_LOG.
5. **RTL و فارسی**: محتوا و رابط فارسی RTL می‌مانند.
6. **حق نشر**: متن/تصویر کتاب رسمی بدون بررسی مجوز بازنشر نمی‌شود؛
   محتوای درس اصلی و برچسب «نیازمند بازبینی معلم» است.
7. **انتشار عمومی**: تا عبور از QUALITY_GATES و تأیید صریح مالک ممنوع؛
   APK داخلی debug-signed معادل release نیست.

## ذینفعان
- کودک کاربر (۱)، والد (دربارهٔ داده و قابلیت آنلاین تصمیم می‌گیرد)،
  معلم پایه اول (گیت اعتبار آموزشی)، مالک پروژه (تأیید انتشار).

## محدوده فعلی MVP
دو درس شمارش (۱–۵، ۶–۹) + آزمون کوتاه؛ دو نوع فعالیت
(countAndChoose/matchCount)؛ گزارش والدین؛ راهنمای محلی قواعد‌محور؛
قرارداد راهنمای آنلاین با کلاینت امن (HTTPS + پین مقصد) — بدون سرور.
