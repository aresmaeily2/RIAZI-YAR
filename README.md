# ریاضی‌یار — آموزش تعاملی شمارش برای پایه اول ابتدایی (نسخه ممیزی‌شده ۱.۰.۳)

اپلیکیشن **Flutter اندروید**، کاملاً **فارسی و RTL**، **آفلاین**، برای کودکان
۶-۷ ساله: شمارش اشیا، تطبیق عدد با دسته‌ها، بازخورد محترمانه، راهنمای گام‌به‌گام
و گزارش والدین. بدون ثبت‌نام، بدون تبلیغ، بدون ارسال داده.

> ⚠️ وضعیت صادقانه: این یک **MVP آزمایشی** است. محتوای درس‌ها نمونه است و پیش از
> استفاده واقعی باید توسط معلم بازبینی شود. اجرای روی دستگاه واقعی هنوز انجام
> نشده است. نسخه ۱.۰.۱ ایرادهای ممیزی امنیتی/حریم خصوصی را رفع کرده است
> (`docs/AUDIT_FIX_v1.0.1.md`، `docs/SECURITY_PRIVACY.md`)؛ نسخه ۱.۰.۲
> یافته‌های ممیزی دوم (`docs/AUDIT_FIX_v1.0.2.md`)؛ نسخه ۱.۰.۳ پاسخ به
> ممیزی مستقل گزارش برنامه‌نویس با راستی‌آزمایی مجدد کامل است
> (`docs/AUDIT_RESPONSE_PROGRAMMER_REPORT_V1.0.1.md`).

## تغییرات ۱.۰.۳ (پاسخ به ممیزی مستقل)

- **تغییر کد کارکردی: صفر.** هر ۹ مورد الزامی ممیزی مستقل در برابر کد فعلی
  مورد‌به‌مورد راستی‌آزمایی شد (کد + اجرای تازه analyze/test روی کامیت تحویل).
- تنها ارتقای نسخه (۱.۰.۲+۳ ← ۱.۰.۳+۴) برای هویت بی‌ابهام بسته جدید و
  جلوگیری از دو APK با نسخه یکسان و بایت متفاوت + مستندات پاسخ ممیزی.
- جدول وضعیت هر ۹ مورد با فایل/سطر/تست به‌عنوان شاهد:
  `docs/AUDIT_RESPONSE_PROGRAMMER_REPORT_V1.0.1.md`.
- NOT RUN (صادقانه): نصب و اجرا روی دستگاه، چرخه کامل HTTPS، بازیابی پشتیبان.
  BLOCKED: انتشار عمومی (امضای انتشار).

## تغییرات مهم ۱.۰.۱ (ممیزی)

- **ورودی گفتار (میکروفون) به‌صورت امن غیرفعال شد** — مسیر پردازش صدای
  SpeechRecognizer دستگاه قابل راستی‌آزمایی نبود؛ مجوز میکروفون و پکیج STT حذف
  شدند؛ مسیر لمسی کودک کامل و آفلاین مانده است.
- **پشتیبان‌گیری اندروید صریحاً غیرفعال شد** — داده کودک فقط روی دستگاه
  (allowBackup=false + قواعد API 31+ و API 23-30).
- **کلاینت راهنمای آنلاین سخت‌سازی شد** — فقط HTTPS با اعتبارسنجی قبل از اتصال؛
  سقف ۸KB جریانی؛ تست‌های جدید.
- **امضا جداسازی شد** — build type «تست داخلی» (debug، برچسب‌دار) جدا از
  «انتشار» (امضانشده — BLOCKED تا تهیه keystore توسط منتشرکننده).
- **پاک‌سازی سورس** — فایل‌های محیطی/تولیدشده از بسته حذف؛ ZIP فقط از فایل‌های
  ردیابی‌شده گیت.

## امکانات

- ۲ درس شمارش (۱-۵ و ۶-۹) + آزمون کوتاه پایان واحد — محتوا در JSON جدا از کد
- ۲ نوع فعالیت: «شمارش و انتخاب عدد» و «تطبیق عدد با دسته‌ها»
- بازخورد فوری، تکرار پرسش تا ۳ تلاش، راهنمای مرحله‌ای بدون لو دادن پاسخ
- راهنمای محلی قاعده‌محور (+ آماده اتصال به راهنمای آنلاین با سرور واسط خودتان)
- TTS فارسی با موتور دستگاه (فقط خواندن متن؛ STT در این نسخه غیرفعال است)
- ذخیره‌سازی محلی SQLite: تلاش‌ها، پیشرفت، تسلط، گزارش والدین
- بخش والدین با گیت ساده + سوییچ صدا/راهنمای آنلاین
- RTL کامل، اعداد فارسی، فونت وزیرمتن، دکمه‌های بزرگ کودک‌پسند

## اجرا و تست

```bash
git clone <این مخزن> && cd riazi_yar
flutter pub get

# تست‌ها (۷۵ تست) + تحلیل استاتیک
flutter config --enable-native-assets && flutter test
flutter analyze

# اجرا روی دستگاه متصل
flutter run --release
```

## ساخت APK (دستور عمومی — بدون مسیر مطلق)

```bash
# نسخه تست داخلی (امضای debug؛ برچسب -internal-test؛ فقط برای آزمون)
cd android && ./gradlew assembleInternalTest --no-daemon && cd ..
# خروجی: build/app/outputs/apk/internalTest/app-internalTest.apk

# نسخه انتشار (امضانشده — امضای نهایی با keystore خودتان؛ انتشار BLOCKED)
flutter build apk --release --target-platform android-arm,android-arm64
```
